# 前端 U3 实施与验收

## 1. 实施结果

资料库成为资料与核对的主要工作区：列表筛选 → 打开详情 → 核对/建任务 → 下一条，不必在两个页面之间来回跳转。

- 资料列表直接提供全部、未分析、待核对、失败、已确认筛选。移除导航里重复的待核对二级入口，主导航“资料”保留待处理总数；日程提醒直接进入相应资料筛选。
- “添加资料”按需展开，支持原有选择图片、粘贴、拖入和文字保存。仅保存仍在本地完成；提取操作明确告知会发送当前资料给模型。
- 已分析资料在共用侧边面板中核对，未分析资料直接展示原始内容。关闭保留筛选、滚动和焦点。手机使用全宽面板，保留底部安全区间距。
- 字段编辑、节点编辑、手动日期和资料输入加入离开保护；关闭、下一条、后退、工作区切换都不会静默清掉未保存编辑。字段保存期间禁用该字段输入，失败时保留草稿。
- 带出处创建任务后，从任务返回原资料和原筛选；不绕去日程。便签与关联任务删除继续走原有影响范围确认，原始资料保留；资料页增加就地“撤销删除”。
- 核对内容抽成 `NoteReview`，资料面板和旧 `/notes`、`/notes/:id` 共用。旧路由、队列、来源返回和字段/任务保护继续保留。
- 原文读取按当前资料和工作区校验，异步切换时清理旧结果与图片 URL，防止迟到的原文显示到另一份资料。

视觉沿用暖白纸面与棕橙主色，以列表、资料详情、必要操作为层级；减少重复说明和同义入口。没有添加介绍横幅或新的视觉框架。

## 2. 交给助手的规则

用户勾选资料后点击“用所选资料制定计划”，助手先展示明确选择的资料清单。确认替换输入后，才进入新计划输入区；仍需用户补充要求并点击生成。

- 只在 URL 传资料 ID 和来源空间，不传原文、图片或整份草案。
- 接收时和最终确认时都校验当前空间、资料存活、重复/非法 ID 及数量限制。失效时整批拒绝，不静默删除一部分选择。
- 不合并助手上一次选中的其他资料，也不自动调用模型。
- 替换前明确提示当前未提交输入会被替换，已保存草案保留；取消交接不改现有输入。
- 生成中、待澄清、结果保存失败、采用中或采用结果待核实时不能用交接覆盖当前工作。
- 这里只接入资料交接；助手整体步骤、预览与确认重组仍属于 U4。
