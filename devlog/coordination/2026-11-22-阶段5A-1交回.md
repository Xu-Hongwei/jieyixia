## 3 路由 / 表单 / 确认映射

### 路由（hash）

| URL | 行为 |
| --- | --- |
| `#/today?date=YYYY-MM-DD&view=list&plan=<id>&undated=1` | date 定选日与周锚；view=list 同七日两区按天竖排；plan 深链接在 ready+当前空间校验后开详情，无效→「安排已不存在或不属于当前空间」+移除参数；显式换周/换日清除不适用 plan；undated=1→全部任务+仅无截止展开 |
| `#/tasks/:id?return=<encoded>` | return 白名单仅 `/today`、`/collect` 前缀，外站/其它路径回落 `/today`（本批补浏览器实证，见 U13）；不存在任务→重定向回列表 |
| `#/today?date=<历史日>&plan=<已删任务安排>` | 历史安排可定位，详情解释「原任务已删除」只读 |

### 表单（唯一 PlanEditor，四模式）

| 入口 | 模式 | 日期初值 | 任务 |
| --- | --- | --- | --- |
| /today ＋安排工作 | create | 实时北京今天（打开时固定一次） | 可搜索选择 |
| 日列＋安排 | create | 该列日期 | 可搜索选择 |
| 任务详情 安排工作 | create | 北京今天 | 固定本任务（无搜索框） |
| 待安排清单 安排 | create | 北京今天；勾选「安排到当前选日」→当前选日 | 固定该任务 |
| 详情 编辑 | edit | 只读 | 只读 |
| 详情 改期 | move | 可改（说明/分钟只读） | 只读 |
| 详情 另安排一天 | arrangeAnotherDay | max(原日期+1, 今天)，可改 | 固定原任务 |

提交按钮文案：创建安排/保存修改/确认改期/创建新安排。分钟初值 30 需显式提交；清空≠自动 30；0/负/小数/非数拒绝。无任务→「先创建任务」入口（脏草稿先确认放弃）。表单永不改 Task 截止、永不创建 Task/Action。
