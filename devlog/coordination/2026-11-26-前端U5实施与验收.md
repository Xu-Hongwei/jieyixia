## 3. 加载实测及边界

生产构建前后对比：

| 项目 | U5 前 | U5 后 |
|---|---:|---:|
| 入口 JS | 1111.32 kB | 663.60 kB |
| 入口 JS gzip | 331.81 kB | 207.70 kB |
| CSS | 37.77 kB | 38.79 kB |

入口 JS 减少约 40.3%，gzip 减少约 37.4%。新增分块为助手 166.59 kB、数据管理 83.57 kB、共享契约校验 201.27 kB。**总 JS 没有同比缩小**，主要收益是移出首次必需下载；入口仍超过 500 kB，构建告警保留。

实际生产预览的首次资源记录：JS 解码后字节数由 1,111,323 降至 663,601；联网挂载后约 1.8 秒开始预加载其余分块，本次记录约 1858ms。此处是延迟定时预加载，不是浏览器空闲调度 API。预加载不调用模型，也不创建长期业务缓存。

证据：[构建前](../../output/frontend-u5-2026-11-26/baseline-build.log)、[构建后](../../output/frontend-u5-2026-11-26/final-build-r2.log)、[浏览器前](../../output/playwright/frontend-u5-2026-11-26/before/metrics.json)、[浏览器后](../../output/playwright/frontend-u5-2026-11-26/after-final-r2/metrics.json)。单次本地加载时间不作为公网速度提升结论。

离线边界：已加载的日常页面继续本地使用；当前会话已加载的数据管理可导出备份。未加载助手时断网，显示无法打开并保留原页；恢复联网后可重试。没有增加 Service Worker，不承诺关闭浏览器后离线冷启动。

## 4. 验证中修复的问题

1. 浏览器会记住失败的动态模块导入，简单重复导航仍可能失败。重试改为重新打开目标页面；先执行当前表单离开确认，断网时禁用按钮，保留已落库数据。
2. 加载失败不会卸载原页面，先前批准离开的临时许可可能残留。路由失败后清除许可，避免用户继续编辑后，下一次重试绕过确认。真实浏览器已验证“失败后新编辑 → 重试 → 取消仍保留输入 → 再确认离开”。

脚本适配：旧流程在点击导航后立即断言助手内容，按需加载后需要等待页面到位；移动端改为定位可见导航。早期失败记录保留，最终通过结果见下一节。

三条人工验收路径（步骤记录，非录屏）：

1. **图文到计划**：助手添加截图/文字与需求 → 生成 → 核对待确认信息 → 看安排预览 → 明确采用 → 日程查看工作与截止。返回编辑、取消离开应保留输入；生成或保存失败应可重试。
2. **任务到执行**：任务清单打开任务 → 安排到某一天 → 日程点安排并编辑 → 选择行动并开始工作 → 结束后确认实际进展 → 回到原任务或日程。取消操作不应落库；改排不应覆盖已投入或保留项。
3. **资料到核对**：资料添加内容 → 打开核对面板 → 确认并创建任务 → 关闭面板回原列表；需要规划时选择资料交接助手。删除先取消检查保留，再确认联删并撤销检查恢复。

自动化已经覆盖相关主链；请人工重点感受信息密度、按钮辨识、返回是否符合预期，避免把自动化通过等同于主观体验验收。
