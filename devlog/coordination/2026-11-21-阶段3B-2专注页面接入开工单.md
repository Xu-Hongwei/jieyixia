# 阶段3B-2 专注页面接入开工单

日期：2026-11-21。状态：待Qoder实施；本文件是设计与验收规则，不表示功能已实现。

前置：3B-0契约0.4.0已通过，3B-1领域/持久化及请求信封整改已通过人工验收。最近已核实基线为315项前端测试、check/build通过。实施前重新核实现场基线，不把历史结果当本轮证据。

## 1 本轮交付与边界

交付闭环：**任务详情选择当前行动 → 开始执行 → 边看资料边写成果 → 暂停/继续 → 结束并选择结果 → 回任务查看工作记录。** 离开后有入口回到同一会话；删除原任务后，已结束历史仍有入口可找。

沿用现有Vue、Pinia、reka-ui与样式系统，只做前端页面、只读资料展示、视图状态及必要的store接线。不新增业务后端API，不修改契约0.4.0、数据库版本、3B-1领域规则或租约阈值，不绕过focus service直接写会话。

不做：多天工作计划、截止/计划双视图、总截止提醒的新设计、自动规划、AI行动建议、统计图、富文本编辑器、附件上传、通知、云同步、备份恢复或部署。日程继续表达现有截止信息，不把专注记录伪装成当日计划卡。

3B-3保留完整多标签竞争、崩溃/时间异常故障注入、删除联删撤销综合验收。本轮仍必须接好既有异常返回、只读/接管/恢复入口，不能以“下批再做”为由让正常刷新无法继续或让保存失败丢输入。

## 2 页面分工与路由

维持「日程 / 资料库 / 待核对」三个主导航。移除侧栏当前不可点击的“专注·后续”占位，不新增专注主导航。

| 页面 | 职责与入口 |
| --- | --- |
| `/today` | 原有日程；增加“工作记录”辅助链接；有未结束会话时显示继续条 |
| `/tasks/:id` | 管理任务与行动、选择当前行动、开始执行、查看本任务工作记录 |
| `/work/:sessionId` | 次级执行页：成果编辑、只读资料、计时、暂停/继续、结束、必要恢复 |
| `/work-records` | 当前工作区已结束会话列表；日期范围与标题/行动搜索，默认全部日期 |
| `/work-records/:sessionId` | 单份已结束记录只读详情；任务有效时可返回任务 |
| `/collect`、`/notes/:id` | 保持收集/核对原职责；执行页看资料优先在页内完成 |

继续使用现有hash路由，深链接刷新有效。所有对象按当前工作区读取；必须等app.ready与本次读取完成，再判定不存在/跨空间。遇无效会话显示说明与返回入口，不白屏、不自动新建、不静默切空间。已结束会话访问执行URL时转只读详情。

来源上下文延续现有任务详情`return`参数：日程周/日/筛选 → 任务 → 执行 → 任务 → 原列表。只接受明确允许的内部路径；详情直接打开没有来源时回日程。浏览器前进/后退与界面按钮使用相同离开规则。

切工作区后退出旧空间的任务/执行/历史详情URL，回目标空间合法列表，不保留原ID。当前App.vue的空间watch也要适配，不能只清query却保留旧`/work/:id`。

## 3 任务详情：开始入口与冲突处理

1. 当前行动区增加唯一主按钮“开始执行”；行动列表仍负责选择当前行动，不在每一行再堆一组计时按钮。无当前行动提示先选择/添加；已完成行动不能开始。
2. 任务有未保存编辑时，先按已有任务编辑规则解决，再调用begin；不能先创建会话、再因离开确认取消而遗留一份运行会话。
3. 点击时捕获当前工作区、任务、行动，签发一次请求；双击/连续Enter复用同一在途请求。提交期间按钮忙碌，begin成功后才跳转执行页。
4. todo开始后由领域规则转doing；blocked明确确认恢复后带现有确认参数调用；done提示先重新打开任务。不得另写一套Task状态变更。
5. 当前空间有未结束会话：同一当前行动按钮为“继续上次工作”；其它行动显示“处理上次工作”，对话框提供“前往上次工作 / 取消”。上次工作结束后由用户重新点击开始，不异步自动开始新行动。
6. 另一工作区占运行位：说明所在空间，提供前往对应空间查看的入口；不能自动暂停、结束或接管另一空间会话。空间切换仍走统一保护。
7. 跳转执行页只打开已有会话；“继续上次工作”是导航，不等于恢复计时。暂停会话仍需用户点击“继续计时”。

## 4 执行页与视觉层级

桌面以编辑区为主，资料区较窄；沿用现有配色与字体，减少重复卡片，不重新做整站主题。

```text
返回任务      当前行动 / 运行或暂停             保存状态
任务标题 · 预计30分钟 · 已投入12:34          暂停/继续  结束本次

本次成果                                  关联资料（只读）
普通文本 / Markdown源码                    本任务关联便签
大面积编辑区                               原始截图 / 原文
                                          同事项补充资料（默认折叠）
```

- 首屏突出“正在做什么、成果写在哪里、是否保存”，计时器不占据大块首屏。
- 标题以会话开始快照为准；当前任务/行动有改动时标注“当前信息已修改”，可查看当前信息，不覆盖历史目标。
- 草稿一个正文输入，不强制三个长表单。空白时用占位提示“记录过程、成果或下次继续的位置”。首版用纯文本/Markdown源码编辑，历史默认按文本安全展示，不引入富文本渲染依赖。
- 手机默认显示成果，资料通过标签/抽屉打开；切资料不卸载/重置编辑草稿。360px宽无整页横向溢出，长中文/英文标题能换行，操作按钮不挤压正文成竖排。
- 保存状态用文字与图标共同区分，错误不能只靠颜色。弹窗支持键盘、焦点回归；计时数字不逐秒通过aria-live播报。

### 资料范围

直接关联资料从Task.note_ids解析，再读取对应Source；同事项资料单独折叠，不能默认展开整个资料库。按ID去重并校验工作区、对象归属。

展示已确认要求/截止、便签文本、原始图片或原文；全部只读，不提供字段确认、AI重跑或编辑原文入口。未确认字段明确标识，不能当成已确认事实。资料缺失或没有关联时显示说明，不能阻断独立任务执行。

图片使用已有本地读取方式，组件正确回收Blob URL；异步加载捕获ws/session/source身份，迟到的旧资料不能出现在新会话。不要把整个可编辑NotesPage嵌进执行页。

## 5 保存、请求与异步规则

### 视图草稿

维护按`workspaceId + sessionId`隔离的编辑控制状态：文本、输入版本、已确认保存版本、在途操作、错误及可重试信封。页面刷新后的唯一已保存事实仍来自IndexedDB。

停止输入约1秒自动保存；只有有效持有者且无恢复阻断时提交。输入版本递增，调用时捕获文本、draftSeq、workspace、session与本次请求信封。保存回调只有匹配当前对象与被提交输入版本时才能标记“已保存”，不得回填覆盖后续输入。

`未保存 / 正在保存 / 已保存 / 保存失败·重试`四态。失败保留输入，不能用重新loadWorkspace的数据库旧正文覆盖编辑框。跨组件卸载仍未提交的文本至少留在会话级内存草稿中，身份隔离；不得宣称它已持久保存。

### 不可变请求信封

- 新操作使用`focus.issueRequest(op, input)`取一次；返回snake_case字段需显式映射为操作输入的`requestId`、`issuedAtMs`，不要直接展开返回对象。
- 同一操作的双击、失败重试与迟到回调复用同一信封和提交内容。用户在失败后改了正文，下一版是新编辑操作；旧回调不能盖掉新版。
- 新的明确开始/保存/暂停/结束各有自己的信封；不能把begin的ID用于end，也不能跨会话复用。
- 不给未知旧ID补当前时间。过期或无法验证时保留输入，展示“本次请求已失效，请核对当前记录后重新提交”；先读取实际状态，再由用户明确发起新操作，不能后台自动换ID反复创建。
- 本批不实现跨刷新在途操作日志。刷新后以数据库事实恢复；若要继续旧请求，只能使用仍有完整信封的重试，不能只凭旧ID猜测签发时间。

### 顺序与版本

保存、暂停、继续、结束通过既有store/service。检查点会推进revision，编辑页须以最新协调状态判断：STALE_REVISION保留本地文本、读取最新事实并提示核对；不得只替换成当前revision再盲目提交旧正文。必要时显式让用户确认采用本地版本。

暂停/继续/结束提交最终正文，使用已有同事务合并能力；不要先在组件直接落库、再改运行状态。结束提交期间冻结表单并停止发起新的自动保存，等待既有写入串行完成，成功才离开。失败解除忙碌并保留正文/表单；不使用beforeunload作为唯一保存渠道。

## 6 计时、暂停与最低恢复交互

预计分钟只作参考，超过不自动结束。实际用时按已验收的accumulated_ms与timer_anchor_at派生，视觉每秒刷新即可，不每秒写库。检查点由既有service调度，页面不另起第二套计时持久化。

| 状态 | 页面行为 |
| --- | --- |
| 当前有效持有者运行中 | 可编辑、暂停、结束；计时显示有效累计 |
| 当前有效持有者暂停中 | 同一会话可编辑、继续、结束；显示累计不增长 |
| 其它页面持有且租约有效 | 正文只读，显示“此工作正在另一页面进行”；刷新状态，不自动接管 |
| 租约到期，包括长暂停后 | 原页也不能直接续写；提供“恢复编辑”显式接管，再核对用时 |
| 待恢复确认 | 显示最后保存累计与未确认间隔，不把间隔自动加成有效用时 |
| 已结束 | 只读详情，不提供继续计时 |

刷新后owner变化；租约未到期先只读，说明何时可恢复。到期后由用户明确takeover，再recover。恢复可选择“保留已保存用时”或“手动修正总用时”；修正用时为非负时长，不是日期时间。墙钟回拨产生负间隔时如实说明需核对，不显示成负投入。

现有recover对原运行会话会恢复运行锚点，不能把它描述为“仅核对但仍暂停”；按钮应明确“核对并恢复运行”。原暂停会话恢复确认后仍暂停，另外点击继续计时。若用户要核对后结束，按当前服务语义先恢复、再提交结束，不伪造新结果或自动完成行动。

失去所有权、RECOVERY_REQUIRED、OWNER_CONFLICT时，停止发起自动写入并保留本地未保存文本；读取最新数据库状态进入只读/核对。不要用无限自动重试掩盖冲突。旧v0未结束会话给出遗留记录说明和显式结束入口，沿用legacyEnd，不补造过去快照。

## 7 离开页面与空间切换

运行中从执行页导航、返回、切任务或切空间，统一提供“保存并暂停后离开 / 留在这里”。有未保存文本的暂停会话也先保存再离开；只有本次成功保存且已无更新输入才继续导航。失败留在原页、原空间并保留输入。

只读非持有者页面不应冒充持有者暂停；若无本地脏输入可正常离开。跨标签未保存冲突文本保留到用户选择，不在切空间时静默丢弃。

路由守卫与WorkspaceSwitcher使用同一个离开协调流程，避免连续两次确认或先切空间后保存。既有app.switchWorkspace已处理运行会话时，页面负责把最终脏文本纳入同一流程；不能两边分别暂停制造竞态。取消后URL、workspace与运行事实保持一致。

正常离开在成功保存/暂停后注销页面订阅与显示定时器；不要在守卫尚未完成时停掉有效service检查点。意外关页只能恢复到最近成功保存的内容，提示本地存储边界，不承诺异步保存必达。

## 8 结束表单与结果

打开结束表单本身不结束、不默认暂停；取消关闭后保持原状态。表单明确单选结果：

| 结果 | 规则 |
| --- | --- |
| 行动完成 | outcome=done；本次确认明确完成该Action，不自动完成Task |
| 部分完成 | outcome=partial；Action保持原状态 |
| 被阻塞 | outcome=blocked；具体卡点必填，Action/Task状态不自动变blocked |

正文是本次成果，不卡必填长文；卡点按既有领域规则校验。Task完成为独立操作，结束不改截止、计划或事项。

最终草稿、计时、结果、卡点及Action显式完成由现有end一次提交。失败留在执行页；成功后回原Task详情，展示“本次工作已记录”及记录入口。Action完成后current_action_id由领域规则清空，不自动选下一条；再次执行需要用户明确选合法行动并新建会话。

既有完成/删除按钮遇未结束会话保护，应提示先前往工作页处理；不能只弹原始错误码。结束以后若想继续原删除，必须再次展示影响并由用户确认，本轮不自动接续删除。

## 9 继续条与历史回看

继续条放当前空间日程和任务详情，执行页不重复显示；也不挤进资料库/核对页成为第二套导航。显示任务/行动、运行或暂停/待恢复状态、“回到工作”一个入口。跨空间运行只在冲突/切换场景提示，不把另一空间记录混进当前继续条。

任务详情列已结束工作摘要：行动快照、北京时间开始/结束、实际用时、结果、卡点及查看成果。按结束时间倒序，同时间稳定排序；累计以毫秒先求和后格式化，不按每段取整分钟相加。

独立工作记录列表默认覆盖当前空间全部已结束历史，支持日期范围和任务/行动标题搜索。任务删后仍能查到历史。断开引用显示“原任务/行动已删除”，不可点失效链接；Task仍有效时仍可返回。旧记录无快照明确标注，不用现名称伪造过去信息。不提供历史编辑/历史批量删除或统计图。

## 12 验收清单

使用隔离浏览器上下文和虚构数据，先列验收数据集，不清个人空间。优先真实页面操作并落库核对；受控时钟只能服务于计时/租约复验，注明哪些不是实际等待。不要靠自动补时间戳的测试包装器替代真实store。

| 编号 | 场景 | 必须证明 |
| --- | --- | --- |
| U01 | 无当前行动、done行动、blocked/done任务 | 入口引导/确认正确，无非法会话 |
| U02 | 单击/双击/连续Enter开始 | 同一意图同信封只生成一段，成功后才导航 |
| U03 | 同空间已有暂停会话、另一空间占运行位 | 引导旧会话，无第二段并行运行 |
| U04 | 运行→暂停→继续→结束 | 同ID、started_at不变、累计正确，暂停不加时 |
