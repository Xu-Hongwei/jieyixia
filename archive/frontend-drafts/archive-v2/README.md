## 使用边界

- 虚构演示数据；页面上的日期也是示例时间。
- 无后端调用，不读取或写入项目原有存储，所有交互刷新后重置。
- 图片和文字仅在当前页面临时预览，未接入 AI 识别或持久保存。
- 逐字段确认后可建立演示任务；新任务显示为未排程，不自动计入今日计划。
- 完成今日计划条目不完成整个任务；专注计时结束也不自动完成任务。
- 字体优先使用 Windows 本机已安装字体；其他系统可能发生回退。
- 本轮只编辑 `frontend-drafts/`。正式前端目录与其他项目源码均未修改。
