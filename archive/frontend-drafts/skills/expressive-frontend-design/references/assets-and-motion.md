# 资产生成、拼装与效果落地

## 1. 主动选择，并执行到底

素材与运动是实现工作的一部分。在视觉丰富的创意任务中，主动寻找能承担视觉主位、材料质感、空间隐喻或情绪表达的资产，不等用户逐次要求“生成图片”“接入视频”。用户明确要求图片、视频或高级素材时，要评估当前可用工具并执行适用部分；不要只返回提示词、资产清单或CSS占位。

执行前区分：

| 任务与表达 | 适合的实际产物 | 执行判断 |
| --- | --- | --- |
| 真实材质、插画、摄影、个性物件、事项封面 | 生成的位图、透明切片或纹理 | 工具可用且已在授权范围内时实际生成并接入；不能只用矩形、emoji或几何SVG代替 |
| 环境氛围、显影、流动材质、循环场景 | 可用工具生成的视频或可控的程序动画 | 需要时间变化时主动检查视频能力，先考虑短循环、构图与播放职责 |
| 精确图标、数据、按钮、动态文字、简单几何 | SVG、HTML、CSS、Canvas | 保持代码原生，真实内容不烘焙进图像 |
| 几何遮挡、相机视角、真实光照、可旋转物件 | 实际3D场景/模型及材质 | 几何与视角是表达核心时实现；若仅需平面摆放，可选择诚实标注的CSS空间表现 |
| 随交互变化的显影、折射、粒子或局部材质 | 实际着色器/渲染逻辑 | 需要像素级交互变化时评估使用，不以静态渐变或普通淡入冒充 |
| 纯文字构想、技能修改、普通功能修复、用户要求极简的工具页 | 相应阶段的说明或原生界面 | 不自动扩展成昂贵的素材工程，也不为凑数量增加效果 |

用户授权的丰富视觉实现应至少让一项有实质作用的非代码原生资产完成生成和页面接入；若所有适用生成工具不可用、现有授权不覆盖或产品确实不适合，记录具体原因与实际替代。此规则不意味着每套每页必须生成图片，更不意味着图片、视频、着色器和3D必须全上。

“有实质作用”需做贡献检查：记录资产增强的是主视觉、物件身份、材料可信度、空间关系还是状态理解；在同一页面临时隐藏或替换它，比较原尺寸和缩略图的损失与收益。用户要求高级素材表现时，几乎不可见的小纹理、无关装饰或与同风格纯色无可辨变化的背景，不能单独满足这一要求。变化很轻但对近看材质确有价值时可保留，须准确说明其有限贡献；不把“必须明显”误解为必须抢正文或夸张装饰。无有意义收益的资产应修改、换接入方式或移除，而非为凑数量留用。

## 2. 小而具体的资产合同

先给每个拟执行资产记录：

```text
资产ID / 对应方案、页面、部件
它解决的画面或体验问题：
产物：生成位图 / 透明物件 / 纹理 / 生成视频 / 程序动画 / 3D / 着色器
光线、视角、色域、尺度与文字安全区：
预计展示尺寸、裁切与桌面/窄屏用法：
生成工具与实际能力 / 产物位置：
组件接入位置与交互职责：
退化方案与通过依据：
状态：计划 / 已生成 / 已加工 / 已接入 / 已验证 / 不适用或受限
```

优先打磨少量关键资产，先生成一份验证美术方向，再扩展同系列。生成随机种子可辅助探索，不能替代光线、尺度和构图约束。不同时为所有方案无差别堆砌同一张纹理。

## 3. 图片生成到组件拼装

1. 发现并调用现有图像生成能力。真实照片/插画/材质类需求不能静默用代码绘图冒充生成素材。
2. 明确主体、视角、材料、光线、色域、比例和安全区。独立物件要求真实透明背景，设置工具对应参数；需要透明却输出不透明时不能假称切片已完成。
3. 检视输出是否适配页面：边缘、背景残留、透视、阴影、纹理颗粒和缩小后的辨识度。需要修改时用支持的图像编辑工具迭代，保留方向不变的要素。
4. 将选中产物放进授权项目目录。记录来源与提示词，并按展示需要裁切、压缩、生成合适尺寸或格式；遵守实际工具对编辑与加工的要求。
5. 在部件中拼装图层：底面/背景、物件、交互内容、阴影与局部效果。控制遮罩、透明边缘、裁切、堆叠、坐标、文字安全区及点击穿透；真实按钮和文本由界面渲染。
6. 在真实桌面/窄屏页面检查，而非仅看独立素材。图片加载失败保留布局和可用入口，不把生成结果只展示在聊天里就结束。

提示词骨架：

```text
用途：{产品 / 方向}的{部件背景或独立资产}，后续将与实时HTML内容拼装。
主体与材质：{物件、边缘、表面与细节尺度}。
构图：{视角、比例、主体位置、裁切和文字安全区}。
美术：{统一色域、光线方向、阴影软硬、风格}。
输出：{透明或不透明、比例、是否可铺贴}。
保留：{交互与正文所在安静区域}。
避免：嵌入UI、真实业务文字、按钮、水印和不相关装饰。
```

普通彩图不自动是可用的法线、粗糙度或深度图；需按渲染器需求实际准备与验证。

## 4. 视频的职责与交付

先发现当前是否有可用视频生成能力；图像生成工具不自动具有视频能力。有合适且获授权的工具时，主动为适合的视频资产定义镜头、时长、循环、光线和文字安全区并生成。需要保持物件身份时用工具支持的参考图流程，不臆造参数或能力。

拿到产物后：保存本地可引用视频、检查实际分辨率/大小/时长，按用途处理编码与裁切，准备poster和静态替代，在页面接入并验证播放。氛围视频通常静音、内联、非必要时不自动播放；有声音或叙事内容提供播放控制。不要用播放失败、海报图或几张素材截图声称视频效果已交付。

检查循环接缝、首次加载、poster到首帧的色差、移动端裁切、可见性变化及减少动态效果。需要暂停的场景不保持无意义后台播放。核心信息和操作不得依赖视频播放成功。

没有视频生成工具时，明确标记“视频生成受限”，可用已生成静帧结合可控的程序动画、序列或静态海报完成适用替代，并按实际技术命名；不称其为生成视频。仅在用户已明确指定某种必需产物、实际无法取得且会改变交付范围时请求其决定，否则先完成不受影响的部分。不得为取得视频擅自注册、购买或扩大外部权限。

## 5. 动画、着色器和3D必须能运行

每套拟实现方向明确一个标志性效果，记录触发、前后业务状态、对象、路径、执行技术、打断/重入与静态替代。技术选择服务表达，不按复杂度排序。

- 页面/对象切换：优先保持对象身份，明确从哪里来到哪里去；不让每次字段确认都把整个工作区重新入场。
- 交互动画：真实运行确认、展开、归组、开始专注等状态，检查连续操作、焦点、输入与取消；一次漂亮的入场不能代表完整动态语言。
- 着色器：实际实现渲染通路、资源与交互参数，检查变化是否有职责；只有CSS渐变、阴影或滤镜时按实际名称说明。
- 真实3D：实际建立或接入几何/模型、相机、灯光/材质及需要的交互。生成的产品照片只属于图像资产，CSS透视只属于CSS空间效果。
- 组合：生成素材可以成为物件表面、部件背景或纹理；交互层仍是可读可操作的真实界面。检查材质与代码光源、阴影和透视是否一致。

效果在浏览器中至少触发一次，再触发、打断或切换一次。需要动态品质证据时录制短过程或记录实际观察；代码存在、截图或动画时长参数均不能证明流畅度。按实际设备检查资源体积和运行表现，不作未经测量的帧率结论。

## 6. 退化与完成判断

窄屏、缺少GPU、加载失败、减少动态效果时提供静态图、简化场景或平面替代；保留相同内容和操作。暂停不可见区域的非必要渲染，控制持续运动范围。复杂效果作用于物件外层，正文与输入区保持稳定。

每个交付资产核对三件事：文件确实存在并可引用、部件确实接入、真实页面确实验证。每个承诺效果核对实现、实际触发、退化表现。生成失败、未使用或未验证的产物保留准确状态，不以素材张数、代码行数或技术名字作为优化成果。

返回 optimization-loop.md 对应层复验。新增素材损坏构图或可读性时回到L1/L2；效果使输入跳动时留在L4修复，不能用视觉评分抵消。
