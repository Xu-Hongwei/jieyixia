# 截下来 · 独立前端视觉草案

双击 `index.html` 即可打开四套方案，不需要安装依赖、启动后端或联网。所有文件均位于本目录，未修改项目其他源码。

| 方向 | 视觉主张 | 默认入口 | 交互主张 |
| --- | --- | --- | --- |
| 01 酸性编辑部 | 荧光绿与黑白排版，把今天做成行动海报 | 今天 | 分层入场、勾选反馈、滚动进度 |
| 02 午夜轨道 | 墨黑与冷蓝，围绕一件事建立沉浸感 | 专注 | 环形计时、工作区切换、暂停恢复 |
| 03 纸上档案 | 纸张与朱红批注，让来源核对成为主角 | 收集箱 | 切换资料、逐字段确认、展开原文 |
| 04 灵感桌面 | 淡紫桌面与复古窗口，让资料有空间感 | 收集箱 | 可拖动便签、窗口层次、底部程序坞 |

每套都可切换今天、收集箱、专注。内容结构为：当前工作区 → 关联资料/今日计划 → 下一步行动。

## 演示范围

- 固定虚构示例，界面明确标识演示；不调用模型或后端，不读取或写入现有 IndexedDB/localStorage。
- 交互状态只保留在当前页面，刷新即重置。独立页面之间不共享状态。
- 完成今日计划条目不完成整个任务；使用示例便签建立演示任务之前需逐项确认所采用的字段。
- 添加文字或图片仅作当前页面临时收集，不执行识别；专注笔记仅作临时输入。
- 未接入正式 Vue、存储、备份、规划算法等产品能力，不能视为 P0 完成或正式前端实现。
- `styles.css` 集中视觉令牌、响应式与减少动效规则；`app.js` 为独立演示行为。

如需本地 HTTP 预览，在本目录运行 `python -m http.server 5188 --bind 127.0.0.1`，打开 http://127.0.0.1:5188 。
