# 真实截图样本（私有测试集）

来源：用户微信收到的 `参考案例(1).zip`（2026-11-17 转入），12 张真实通知截图。
**本目录是私有测试集，不是演示素材。** 与 `fixtures/assets/` 的区别见下。

## 为什么不能进交接包 / 演示 / 公开仓库

抽查发现含真实可识别信息：

| 类别 | 出现位置（举例） |
| --- | --- |
| 真实学校名 | 专业实践、竞赛通知 |
| 真实教师姓名 | 竞赛通知 |
| QQ 群号 | 竞赛通知 |
| 在线文档链接（可能含名单） | 党课培训、奖学金申报 |
| 楼宇房间号 / 办公地点 | 专业实践、开题报告 |

因此：

- 根 `.gitignore` 已排除 `samples/real/`。
- 交接 zip **不包含**本目录。
- F12 演示只用 `fixtures/assets/` 的虚构渲染图。
- 若要把某张真实图用于演示，必须先脱敏（抹掉上表全部类别）并经用户确认，另存到 `fixtures/assets/` 并标注来源与脱敏日期。
- devlog 与对外文档只写文件名与问题类别，**不抄录姓名、群号、链接原文**。

## 已发现并修复的问题（2026-11-17）

1. 相对词旁括号明确日期被相对推算覆盖 → `extract_explicit_date()` 让明确日期优先。
2. 缺年份月日（含 `5.12` 点号格式）整条丢失 → 补年份并标 `derived + unresolved` + `date_year_inferred` warning。
3. 点号/斜杠月日格式未识别 → `_MONTH_DAY_DOT`。

回归测试见 `backend/tests/test_model_core.py`。

## 仍未解决（记入契约 v0.2 议题）

- **多截止节点**：实验室把两个 deadline 挤进一个字符串。`Field.value` 应支持 `[{label, value, precision}]`，Task.deadline 由用户选定其一。属破坏性变更，需评审。
- **礼貌语混入 requirement**：放假安排的「请知悉，谢谢」进了 requirement。prompt 调优项。
- 手机拍屏（摩尔纹/反光/透视）、多栏排版、手写批注仍未测——本批均为干净文字截图。
